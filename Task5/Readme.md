# Laundry Services Hero Section

A laundry services landing page hero section created using HTML and CSS.

## Project Overview

This project recreates a modern laundry services website hero section. It includes a navigation bar, logo, username button, promotional heading, description, call-to-action button, and a laundry machine image.

The design is built using responsive CSS and viewport units.

## Features
* Navigation menu
* Logo section
* Username button
* Promotional heading
* Highlighted “Laundry Services!” text
* Call-to-action button
* Laundry service image
* Gradient button background
* Google Poppins font
* CSS Grid layout
* Viewport-based sizing

## Technologies Used

* HTML5
* CSS3
* Google Fonts
* Viewport units (`vw` and `vh`)

## How to Run the Project

1. Download or clone the project.
2. Open the project folder.
3. Make sure the image file is available in the project directory.
4. Open `index.html` in a web browser.

## Font

The project uses the **Poppins** font family from Google Fonts.

```css
font-family: 'Poppins', sans-serif;
```

## Layout

The page uses CSS Grid to organize the main sections:

* Header with logo, navigation, and username button
* Two-column hero section
* Left column for text content
* Right column for the laundry image
