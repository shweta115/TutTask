# Laundry Login Page

A responsive Laundry Service Login Page designed using **HTML5**, **CSS3**, and **Flexbox**.

## 📌 Project Overview

This project is a simple and modern login page for a laundry service application. The page contains two main sections:

- A laundry illustration section
- A user login form section

The layout is created using **CSS Flexbox**, making it easy to align and organize the content.

---

## 🛠 Technologies Used

- HTML5
- CSS3
- CSS Flexbox
